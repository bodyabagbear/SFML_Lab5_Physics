# Моделювання руху тіла похилою площиною
Цей проєкт є програмною реалізацією Лабораторної роботи №5 (Варіант 17). 
Програма моделює фізичний процес ковзання тіла з урахуванням сили тяжіння та сили тертя.
## Технології
- Мова програмування: **C++**
- Графічна бібліотека: **SFML 3**
- Середовище: **Visual Studio / CMake**
## Керування в програмі
- Стрілки **ВГОРУ** та **ВНИЗ** — зміна кута нахилу площини.
- Стрілки **ВЛІВО** та **ВПРАВО** — зміна коефіцієнта тертя ковзання.
- Клавіша **ПРОБІЛ** — перезапуск симуляції (повернення тіла на початкову позицію).
